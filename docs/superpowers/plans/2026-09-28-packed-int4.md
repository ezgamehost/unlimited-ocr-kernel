# Packed INT4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement packed W4A8 CPU inference that preserves the successful INT4 simulation's arithmetic and earns acceptance through full-model measurements.

**Architecture:** Add a separate versioned packed overlay and Int4Matrix kernels, retaining Q8 and original BF16 paths. Decode uses block32 signed nibbles, FP32 scales and the existing dynamic activation quantization. Multi-row prefill expands packed weights into the same FP32 matrices used by the simulation.

**Tech Stack:** Rust, ARM NEON/SDOT with runtime detection, portable scalar fallback, Apple Accelerate, Python/NumPy safetensors preparation.

**Spec:** `docs/superpowers/specs/2026-09-27-rust-unlimited-ocr-design.md`; accuracy gate in `docs/benchmarks/2026-09-28-int4-accuracy/PLAN.md` and its completed README.

## Global constraints

- Original BF16 remains the default; existing Q8 and simulation artifacts remain readable.
- No output/performance claim from packing alone; full inference must be measured.
- Source and overlay hashes, complete matrix sets, dtype and shapes remain mandatory.
- The eight synthetic pages used in precision selection are no longer unseen Q4 validation.
- Keep original versus matched-newline prompt results explicit; use original prompt for the simulation equivalence check.

## Packed format

`uocr-q4-block32-v1`, block_size=32, storage_bits=4, weight_bits=4.
For a source matrix `[rows, cols]`, stored weights have safetensors dtype U8 and
shape `[rows, ceil(cols/32), 16]`. Scale tensor name is `<weight-name>.q4_scales`,
F32 shape `[rows, ceil(cols/32)]`. Within each 32-element block, byte j holds
weight j in its low nibble and weight j+16 in its high nibble (two's-complement).
Codes are -7..7; -8 is forbidden. Missing columns in the final block are zero.
FP32 scales match the unpacked simulation exactly. Original dimensions come
from the pinned source descriptor, not inferred from padded storage.

Manifest keeps schema_version1, format, block_size, source/output SHA256,
matrix_count, file bytes, and weight_bits/storage_bits. Mandatory header fields
match the sidecar; mismatches are errors. No mixed Q8/Q4 matrices in this version.

## Review focus

- Tail nibbles, sign extension, forbidden -8 and nonzero padding must be rejected or decoded correctly before unsafe access.
- Overflowing shape products, missing scales, invalid dtypes/scales and forged sidecars must fail before matrix dispatch.
- SIMD must not run without dotprod support; odd columns/rows must use valid tails/fallback.
- Decode multiplication/addition order must preserve the simulation; do not introduce FMA contraction.
- CLI precision labels must identify actual packed Q4; existing flags and Q8 artifacts must remain compatible.
